Why 0.1.0. The group has produced APKs before - SALINLAHI_VoiceTest.apk, _v2,
_v3 and the Mid-Act7 SALINLAHI.apk - but none carried a version number, none
was tested as a package, and none can now be tied to a commit. This is release
number one under a controlled process, so it takes the first number. The
feature set is larger than a "first build" would suggest; the version counts
releases, not features.


INCLUDED IN THIS VERSION
------------------------

Gameplay
  15 playable scenes across three places: Bahay (home, 5), Paaralan (school,
    5) and Parke (park, 5).
  54 distinct Filipino words taught across 74 spoken objectives - among them
    Bangon, Tayo, Lakad, Kaliwa, Kanan, Tabo, Sabon, Sipilyo, Tuwalya,
    Maligo, Suklay, Damit, Medyas, Sapatos, Kanin, Itlog, Kain, Inom, Bati,
    Pasok, Lapis, Aklat, Basa, Sulat, Sagot, Akyat, Dausdos, Talon, Kumusta,
    Ngiti, Salamat and Paalam.
  Each word drives one action - standing up, walking, turning, opening a door,
    switching on a light, taking an object, bathing, dressing, climbing,
    sliding, jumping, greeting a friend, sharing food, going home.
  Levels unlock in order along a journey map.

Voice
  Continuous listening through the device's Filipino (fil-PH) speech
    recognizer.
  Pronunciation judged by Filipino phonology rather than by letter-edit
    distance. Words the game teaches in the same scene are no longer accepted
    for one another in the checker's own tests: Kain/Kanin, Tabo/Takbo,
    Tawa/Tuwa, Bati/Bata and Kanan/Kanin all previously passed for each other.
    NOTE: on a real device this is NOT yet delivering what it should - see
    Known Issues, first entry.
  Known mishearings per word are accepted, so a recognizer quirk does not
    count against the child.
  Every attempt is logged on the device, so the accepted variants can be
    tuned from real playtest data.
  Mic and replay buttons, with listening / correct / try-again / mic-blocked
    states shown on screen.

Progress and scoring
  Named player profiles, several per device, saved locally as players.json.
  Nickname entry with availability checking and suggestions.
  Per-scene score, stars and a "words learned" panel with English meanings.

Leaderboard
  One shared online board, written through a Supabase Edge Function
    (submit-score) and read back over REST.
  Only four values leave the device: player id, nickname, total points and
    total stars. Learning data and voice attempts stay on the phone.
  A failed upload is retried the next time the main menu opens.

Presentation
  423 recorded Teacher Rachel voice-over clips, in the group's own voices.
  Music per place, sound effects, and separate master / effects / narration /
    music volume controls with mute.
  Main menu with profile card, settings and about popups.


FIXED
-----

  The app reported no version at all. There is now a version in the About
    screen, read from the build itself, and a BUILD_INFO.txt beside every
    artifact naming the commit it came from.
  The Android package id was still the Unity default,
    com.DefaultCompany.SALINLAHI.
  Internet access is now requested explicitly in the manifest rather than
    left to Unity's auto-detection, which the hosted leaderboard depends on.
  Releases had no repeatable procedure. One build entry point now produces the
    package - see Docs/RELEASE_PROCESS.md.


KNOWN ISSUES
------------

  WRONG PRONUNCIATION IS STILL ACCEPTED ON A DEVICE. This is the most serious
    issue in the release and it affects the game's central purpose. The
    pronunciation checker rejects wrong vowels in its own unit tests, but the
    v0.1.0 device test found that a mispronounced word is still accepted
    during play. The likely cause is that the device's Filipino dictation
    service returns the nearest real Filipino word rather than the sounds the
    child actually made, so the checker is handed an already-corrected word and
    never sees the mistake. If that is confirmed, it cannot be fixed inside the
    checker and needs a different recognition approach. Until then, treat the
    right/wrong judgement as unreliable: the game still teaches and prompts the
    vocabulary, but it does not yet reliably correct pronunciation.
    This is why v0.1.0 is a testing build and not a stable release.

  15 of Teacher Rachel's repeated lines have no recording: the three framing
    lines ("Sabihin", "Ngayon", "Ulitin"), the listening cue, two hints, the
    idle nudge, the mic-blocked line, and the correct / incorrect / not-heard
    replies. These are the lines heard most often. The written caption is
    shown and the pause is held, so the game stays playable but is quieter
    than intended.
  The opening prompt of a scene holds a long silent pause before the child is
    allowed to speak.
  The MINI GAME button on the main menu is drawn but does nothing.
  Teacher Rachel's portrait image is not assigned, so her captions appear
    without her picture.
  Word badges sit low on the screen in Paaralan 2, Paaralan 5 and Parke 4.
  No voice input without an internet connection; offline recognition is off.
  Suspend and resume behaviour has not been tested on a phone with the
    speaker at full volume.
  The game cannot be answered by voice on desktop at all; the speech plugin is
    Android and iOS only. A desktop build is not released for this reason.

INSTALLATION / RUNNING INSTRUCTIONS
-----------------------------------

See README.txt in this folder. In short:

  1. Uninstall any older SALINLAHI build first - the package name changed.
  2. Copy SALINLAHI-v0.1.0.apk to an Android 8.0+ device and open it.
  3. Allow installation from this source, then allow the microphone.
  4. Stay online, turn the volume up, and say the Filipino word on screen.

Confirm the build by opening SETTINGS > ABOUT; it should read v0.1.0.
