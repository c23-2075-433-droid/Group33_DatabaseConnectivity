SALINLAHI - ElevenLabs API key
==============================

Tools/generate_music.py (and the voice-over generator) read the key from
Tools/elevenlabs.key, which is git-ignored so it never lands in the
repository. This file is the committed stand-in that says how.

Create yours once:

    printf '%s\n' 'sk_your_key_here' > Tools/elevenlabs.key
    chmod 600 Tools/elevenlabs.key

Or export it instead, if you would rather keep nothing on disk:

    export ELEVENLABS_API_KEY='sk_your_key_here'

Get the key from https://elevenlabs.io/app/settings/api-keys.

IMPORTANT
---------
  This is a BILLING credential, not a public key like the Supabase anon key.
  Anyone who has it can spend the plan's credits. Never commit it, never
  paste it into a chat or a report, and never pass it on a command line -
  arguments are visible to every process on the machine and land in your
  shell history. The tools only ever read it from the file or the
  environment, and they print where they found it, never what it is.

  The credits are shared between music and speech: about 900 per minute of
  music, and one per character of voice-over.
